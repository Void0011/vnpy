# 定投回测开发与启动

项目包含桌面定投回测、银河证券流水分析和独立飞书提醒脚本。桌面入口为 `run.py`，提醒入口为 `scripts/dca_reminder.py`。

## 固定使用项目环境

在项目根目录创建虚拟环境并安装开发依赖（建议 Python 3.12/3.13）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e '.[dev]'
.\.venv\Scripts\python.exe -m pip install vnpy_ctastrategy vnpy_ctp vnpy_sqlite
```

已有完整 VeighNa/Conda 环境时，也可以从该解释器创建 `--system-site-packages` 虚拟环境，复用已安装 GUI 和交易模块；其他新增依赖仅安装到 `.venv`。本机此次恢复使用了这种方式。不要把 `.venv` 上传到 Git。

统一入口避免 PATH 意外切换解释器：

```powershell
./scripts/dev.ps1 test
./scripts/dev.ps1 check
./scripts/dev.ps1 build
./scripts/dev.ps1 run
```

`run.py` 保留原有 CTP / CTA 模块及实际下单入口。定投回测不需要开启实际定投，实际交易仍需独立配置交易接口。

wheel 包含 `vnpy` 和本项目定制的 `vnpy_ctabacktester`。不要再用上游同名回测包覆盖本项目的定制模块。

完整 Alpha 因子测试在独立 CI 环境安装 `.[alpha,dev]` 后运行。当前 Alpha 的间接依赖 `empyrical-reloaded` 与桌面 `vnpy_sqlite` 对 `peewee` 的版本要求冲突，应使用分开的环境，不要把 Alpha 依赖直接叠加到桌面交易环境。

## 桌面和提醒的计算口径

两端三种周期策略已增加相同输入下的对照测试 `tests/test_dca_parity.py`。

| 项目 | 桌面回测 | 飞书提醒 |
|---|---|---|
| 默认回撤 / BIAS 窗口 | 250 日，可在 UI 修改 | 120 日，可在 JSON 修改 |
| 价值平均默认每期增长 | 10000，可在 UI 修改 | 4000，可在 JSON 修改 |
| 回撤 / BIAS 基础金额 | UI 指定；未指定时由初始份额和价格推算 | 4000 |
| 默认执行周期 | 20 个交易日，价值平均单独配置 | 20 个交易日 |
| 周期起点 | 回测区间首个有效交易日 | 固定锚点 2026-07-01 |
| A 股日线复权 | 未复权 | 前复权 qfq |
| 持仓口径 | 区间从零模拟 | 从锚点模拟；或显式 actual 持仓 |

为了保留历史回测结果，没有悄悄改变桌面的默认参数或数据复权方式。验证两端结果时应使用**同一价格序列、参考窗口、基础金额、目标增量、起点及周期**；同一天的不同复权数据不能直接比较。提醒会下载锚点之前的指标预热行情，桌面起点附近可能只有不足完整窗口的数据。回测价格为当根 K 线收盘价。

## 个人收益排名

“买入贡献排名”保留原实现：按每笔买入对当前收益的贡献排列前三/后三，图中标注“优 / 差”。这不表示该日账户收益率变化最大。

“每日收益率变化”按相邻可用日线计算：

```text
日末收益 = 日末持仓 × 收盘价 + 截至当日累计卖出回款 − 截至当日累计买入支出
日末简单收益率 = 日末收益 / 截至当日累计买入支出 × 100%
收益率变化（百分点）= 当日简单收益率 − 上一个可用交易日简单收益率
```

仅使用截至该日已发生的交易，买卖现金流包含导入流水中的实际费用。保留前三个正变化日、前三个负变化日，分别标注 R+ / R−；首日不排名，正负变化不足三项时不补凑。表中提供对比日期，缺失日线不插值。当日即使没有买卖也可能入选。该指标包含新增投入和费用的影响，不是时间加权收益率，也不表示某次交易导致市场波动。

完整清仓后的无持仓日期不再重复展示。分红/拆股等非买卖流水尚未纳入现金流模型；XIRR 仍属于单独的可选扩展。

## 发布检查

本项目 fork 的 `master` 保留用于同步官方 `vnpy/vnpy`；定制功能在 `codex/dca-live` 维护，并将该分支设为 fork 的默认分支供定时提醒运行。后续升级先同步 `master`，再合并到定制分支并执行测试；合并冲突在定制分支解决。不要使用丢弃本地提交的强制同步覆盖定制分支。

- 运行上述 test / check / build；提醒任务单独运行标准库 unittest。
- 明确列出拟提交文件；`.vntrader/`、原始交易流水、`.env`、`.history/`、个人会话报告应留在本地。
- Secrets 只存 GitHub，不出现在源码、配置和日志。
- 上线与验收步骤见 [飞书提醒说明](dca_feishu_reminder.md)。
